# Учебные материалы по MLOps / LLMOps

Магистратура «Искусственный интеллект», НИУ ВШЭ.

Практический курс: от структуры ML-проекта до продового сервинга ML- и LLM-моделей.
Каждая тема — лекция (`.pptx`) и семинары-воркшопы; крупные темы поднимают рабочий
стек на `docker-compose` с управлением через `make`.

Предполагаемые базовые знания: Docker, Docker Compose, Python, основы Classic ML, CV, TextGen.

## Быстрый старт (в темах со стеком)

```bash
cp .env.example .env      # заполнить ключи (OpenAI и т.д.)
make up                   # поднять весь стек
make init                 # инициализация: БД, пользователи, коллекции
make ps                   # статус сервисов
make logs                 # логи
make down                 # остановить
```
