# 01 — Инструменты и структура ML-проекта

**Преподаватель:** Марк Блуменау · **Формат:** 1 лекция / 1 семинар

Управление зависимостями и окружением, версионирование данных, единая структура
ML-проекта и воспроизводимость.

## Содержание

- **uv**, **poetry** — управление зависимостями и окружениями
- **dvc** — версионирование данных и артефактов
- **pre-commit** — хуки качества кода
- **hydra** — конфигурирование экспериментов
- **fire** — CLI из кода без бойлерплейта
- Каноническая структура ML-проекта
