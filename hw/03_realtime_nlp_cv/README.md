# ДЗ 03 — Real-time NLP / CV инференс

**Преподаватель:** Евгений Чернов

Единый gateway, отдающий два вида инференса под нагрузкой:

- `/vision` — классификация изображений (ResNet50 / ImageNet, top-5) на **Triton**
- `/chat` — OpenAI-совместимый стриминг (SSE) на **vLLM**

Доступ по **JWT**, наблюдаемость через **Prometheus / Grafana**.
