# ДЗ 02 — Real-time NLP / CV инференс

**Преподаватель:** Евгений Чернов

Единый gateway, отдающий два вида инференса под нагрузкой:

- `/vision` — классификация изображений (ImageNet, top-5) на **Triton**; CV-модель у каждого
  студента своя по email: ResNet50 / EfficientNet-B0 / MobileNetV3 / ConvNeXt-Tiny
- `/chat` — OpenAI-совместимый стриминг (SSE) на **vLLM** (Qwen2.5-1.5B-Instruct)

Доступ по **JWT**, наблюдаемость через **Prometheus**. Грейдер проверяет не только ответы
ручек, но и метрики Triton/vLLM: решение в обход бэкендов теряет большую часть баллов.

## Запуск и сдача

Требуется NVIDIA GPU. Модель `model.onnx` не хранится в репозитории — её экспортирует
`make init`. Постановка, контракт API, критерии и порядок сдачи в грейдер
(`http://51.250.34.2:9000`, 5 попыток) — в [`ЗАДАНИЕ.md`](student_template/ЗАДАНИЕ.md).
