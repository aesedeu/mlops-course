# 00 — Знакомство с курсом

Вводная дека для первой встречи со студентами: для чего курс, чему научатся,
программа занятий, домашние задания и преподаватели.

## Материалы

- Презентация: [intro.pptx](intro.pptx)
- Исходник (pptxgenjs): [build.js](build.js) — использует общий [`../theme.js`](../theme.js)
- Фото преподавателей: `img/`

## Сборка

```bash
NODE_PATH=$(npm root -g) node build.js   # → intro.pptx
```
