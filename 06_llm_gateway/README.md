# 06 — LLM-гейтвей + observability, RBAC, API

**Преподаватель:** Евгений Чернов · **Формат:** 1 лекция / 2 семинара

Продовый слой вокруг LLM: единый шлюз к моделям, наблюдаемость и стоимость,
ролевой доступ и API, агент с персистентной памятью.

## Стек

**LiteLLM** (LLM-прокси) + **Langfuse** (LLM observability) + **Qdrant** (векторная БД) +
**FastAPI** (JWT / RBAC / rate-limit) + **LangGraph** (агент с персистентной памятью в Postgres) +
**Prometheus / Grafana**.
