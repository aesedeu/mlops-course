# 05 — vLLM · SGLang

**Преподаватель:** Иван Копылов · **Формат:** 2 лекции / 2 семинара

Высокопроизводительный сервинг LLM: движки инференса, батчинг запросов, потоковая
генерация.

## Содержание

- **vLLM** — PagedAttention, continuous batching, OpenAI-совместимый API
- **SGLang** — структурированная генерация, RadixAttention
- Потоковая генерация (SSE), параметры сэмплинга
- Замеры throughput / latency под нагрузкой
